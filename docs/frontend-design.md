# CRISPRloci v2 interface direction

Keep the established analysis form, recovery link and evolution explorer. The
new visual anchor is a genomic locus: repeat/spacer blocks beside Cas-gene arrows
and a tracrRNA candidate, with coordinates carried into the result view.

- Paper #f5f8fc; ink #12324d; array teal #0f766e; Cas blue #3158a5;
  candidate amber #a76716; muted text #52647a.
- Aptos / Segoe UI for forms and prose; the existing monospace stack only for
  sequences, identifiers and exact coordinates.
- Left-aligned heading and form; six analysis choices in two rows on desktop and
  one column on phones. Results are ordered by genomic question, not implementation.
- Preserve keyboard controls, contrast, reduced motion and the no-storage recovery
  contract. Use tables for precise evidence and a locus strip for spatial context.

Review: retain the inherited controls where users already know their meaning;
replace the evolution-only headline and diagram with locus context. Avoid adding
unrelated dashboards, marketing metrics or decorative animation.
