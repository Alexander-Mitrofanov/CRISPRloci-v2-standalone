# Documentation guide

For current release information, start with:

- [README](../README.md): installation, analysis modes, configuration and results.
- [Bug-fix log](../BUGFIX_LOG.md): problems corrected in each development phase.
- [Benchmark log](../BENCHMARK_LOG.md): measurements, denominators, controls and limitations.
- [Migration](MIGRATION.md): v2 behavior changes, CLI aliases and output schema.
- [Dependencies](DEPENDENCIES.md): upstream contracts, installation and update recovery.
- [Final engineering review](code_quality/08_final_outcome.md): 360 unit tests,
  seven native integrations, packaging checks and independent acceptance.

The literature report, scientific improvement plan, reproducibility amendment,
`council/` and `code_quality/` preserve the original development/audit record.
Earlier test counts describe those stages, not the latest suite. Original absolute
paths and links to workspace-only evidence may appear in these records; see
[benchmark artifact scope](../benchmarks/README.md) for what is distributed in Git.
The frozen plans and results have not been rewritten to imply new experiments.
